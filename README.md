# KKminer
### 专注头矿币种的轻量化挖矿软件

致力于打造稳定高效、易用省心的挖矿工具，做最好的挖矿软件！

## ✨ 核心特性
- 支持 **Pearl (PRL) 珍珠币** Windows 平台挖矿
- 完美适配多显卡并行挖矿，算力调度更稳定
- 全面支持 NVIDIA / AMD / Intel 全品牌GPU挖矿
- 支持 AMD / Intel 平台CPU挖矿，覆盖更多硬件场景
- 公益免费开放使用，全程无任何抽水
